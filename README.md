# 工程カレンダー（アプリ版）

にんにく作業の工程管理アプリ。ホーム画面に追加して、アプリのように使えます。

## 使い方
1. ファイル一式を、静的サイトとして公開します（Netlify Drop など）。
2. 携帯のブラウザでURLを開き、「ホーム画面に追加」します。
3. 最初に「データを読み込む」で、バックアップのJSONを読み込みます。

## 保存
- データは、この端末のブラウザの中に保存されます。
- 端末を変えるときや、念のための控えは、「データを書き出す（バックアップ）」で保存します。

## Excel
- 「Excel出力」「Excelに反映」「Excelから取り込む」が使えます。
- 初回だけ、Excelの部品（ExcelJS、JSZip）をインターネットから読み込みます。

## 注意
- 企業名や従業員名などのデータは、このファイルには入っていません。
