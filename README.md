# 工程カレンダー（アプリ版）

にんにく作業の工程管理アプリです。GitHub Pagesで公開しています。
公開URL: https://olive-an.github.io/olive-koutei/

## しくみ
- 画面（このリポジトリ）: 企業名や予定などのデータは入っていません。
- データ: 担当者のGoogleスプレッドシート（GAS）に保存します。共有URLは、アプリの「共有の設定」で、各端末に入れます。
- 端末にも、同じ内容が保存されます。電波がないときも、使えます。

## 使う人
- 決まった担当者だけが使います。共有リンクは、担当者以外に送らないでください。

## 更新するとき
- index.html などを変えて main に入れると、1〜3分で公開されます。
- gas/Code.gs は、スプレッドシート側に貼る共有用のコードです。

## Excel
- 「Excel出力」「Excelに反映」「Excelから取り込む」が使えます。
- 初回だけ、Excelの部品（ExcelJS、JSZip）をインターネットから読み込みます。
